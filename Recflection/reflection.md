# Cloud Computing Reflection Paper

Cloud computing has become a part of my everyday life because I regularly use different online services. Many applications that I use for communication, entertainment, and productivity rely on cloud technology to provide fast and convenient access to information.

Three cloud services that I use regularly are Google Drive, Messenger, and Canva. Google Drive is an example of Software as a Service (SaaS) because it allows users to store and access files through the internet. It uses the public cloud model because its services are available to millions of users worldwide.

Messenger is another example of SaaS because it provides messaging services through internet-connected devices. Like Google Drive, it also uses a public cloud deployment model because it is available to a large number of users.

Canva is also classified as SaaS because users can create and edit designs online without installing complicated software. Since it is accessible to the public, it operates through a public cloud environment.

Version control is important because it allows developers to track changes, identify mistakes, and restore previous versions of files whenever necessary. GitHub makes collaboration easier because team members can contribute to projects while maintaining an organized record of updates and modifications.

As a student, learning Git and GitHub will help me improve my technical skills and prepare me for future careers in the field of technology.
