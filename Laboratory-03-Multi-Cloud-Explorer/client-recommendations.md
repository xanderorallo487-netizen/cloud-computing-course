# Client Recommendations

## Client A – Startup Company

**Recommended Platform: AWS**

I recommend AWS for the startup company because it has many services that can be started with a small amount of resources. The company can increase its cloud resources as the number of users grows. AWS also provides different services that can help the company build and manage its mobile application.

**Possible Services:**
- Amazon EC2
- Amazon S3
- Amazon RDS

## Client B – University

**Recommended Platform: Microsoft Azure**

I recommend Microsoft Azure because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure can work well with these Microsoft technologies and can help the university move some of its services to the cloud.

**Possible Services:**
- Azure Virtual Machines
- Microsoft Entra ID
- Azure SQL Database

## Client C – AI Research Company

**Recommended Platform: Google Cloud Platform (GCP)**

I recommend GCP because the company develops Artificial Intelligence and Machine Learning applications. Google Cloud provides services and computing resources that can be used for AI workloads and high-performance computing.

**Possible Services:**
- Compute Engine
- Vertex AI
- Google Kubernetes Engine (GKE)

## Client D – Global E-Commerce Company

**Recommended Platform: AWS**

I recommend AWS because the company serves customers around the world and needs highly available infrastructure. AWS provides global infrastructure and services that can automatically scale when the number of users increases.

**Possible Services:**
- Amazon EC2 Auto Scaling
- Elastic Load Balancing
- Amazon S3
