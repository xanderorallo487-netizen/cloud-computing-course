# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many services for computing, storage, networking, databases, security, and application development. AWS allows users and businesses to use cloud resources without needing to maintain their own physical servers.

## Global Infrastructure

AWS has cloud infrastructure in different parts of the world. It uses Regions and Availability Zones to provide reliable cloud services. This allows companies to run their applications in different locations and helps improve availability and performance.

## Cloud Management Console

The AWS Management Console is a web-based interface used to manage AWS services. Users can create and configure resources, check their services, monitor applications, and manage their AWS account. It provides access to many AWS services from one place.

## Four Core Services

1. **Amazon EC2** – Provides virtual servers that can be used to run applications and operating systems.
2. **Amazon S3** – Provides object storage for files, backups, images, videos, and other data.
3. **Amazon VPC** – Provides a private network where AWS resources can communicate with each other.
4. **AWS IAM** – Manages users, roles, and permissions for AWS resources.

## Three Advantages

1. **Wide Range of Services** – AWS provides many services for different types of cloud projects.
2. **Global Infrastructure** – AWS has infrastructure in many locations around the world.
3. **Scalability** – Resources can be increased or decreased depending on the needs of an application.

## Typical Enterprise Use Cases

AWS can be used for websites, mobile applications, online stores, databases, backups, data analytics, file storage, and large-scale applications. Many organizations also use AWS to host applications and services without maintaining physical servers.
