# Laboratory 03 – Multi-Cloud Explorer

## Course Information

**Course:** CCM101 – Cloud Computing  
**Laboratory:** Laboratory Activity 3  
**Mission:** Become a Multi-Cloud Explorer

## Introduction

This laboratory activity focuses on exploring and comparing three major cloud computing platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

The goal of this activity is to understand the main services offered by each cloud provider and identify which platform is more suitable for different business needs.

## Objectives

After completing this laboratory activity, I should be able to:

- Explore major public cloud platforms.
- Identify the core services of AWS, Azure, and GCP.
- Compare similar cloud services from different providers.
- Analyze business requirements and recommend a cloud platform.
- Create technical documentation using Markdown.
- Organize my Cloud Computing GitHub Portfolio.

## Cloud Platforms

### Amazon Web Services (AWS)

AWS is a cloud platform provided by Amazon. It offers services for computing, storage, networking, databases, security, and application development.

Some important AWS services are:

- Amazon EC2
- Amazon S3
- Amazon VPC
- AWS IAM

### Microsoft Azure

Microsoft Azure is Microsoft's cloud computing platform. It provides services for computing, storage, networking, databases, identity management, and other cloud solutions.

Some important Azure services are:

- Azure Virtual Machines
- Azure Blob Storage
- Azure Virtual Network
- Microsoft Entra ID

### Google Cloud Platform (GCP)

Google Cloud Platform is Google's cloud computing platform. It provides services for computing, storage, networking, databases, artificial intelligence, machine learning, and application development.

Some important GCP services are:

- Compute Engine
- Cloud Storage
- Virtual Private Cloud (VPC)
- Cloud IAM
