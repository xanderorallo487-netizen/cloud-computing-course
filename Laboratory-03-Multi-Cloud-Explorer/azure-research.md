# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides different services for computing, storage, networking, databases, security, identity management, and application development. Azure allows users and organizations to use cloud resources without maintaining their own physical servers.

## Global Infrastructure

Azure has cloud regions and data centers in different parts of the world. These regions help organizations run their applications closer to their users. Azure also provides availability features that can help keep applications and services running even when there are problems in one location.

## Cloud Management Console

The Azure Portal is a web-based interface used to manage Microsoft Azure services. Users can create and manage virtual machines, storage accounts, databases, networks, and other resources. It also provides tools for monitoring and managing cloud resources.

## Four Core Services

1. **Azure Virtual Machines** – Provides virtual computers that can be used to run applications and operating systems.
2. **Azure Blob Storage** – Provides object storage for files, images, videos, backups, and other data.
3. **Azure Virtual Network** – Provides networking for connecting and controlling Azure resources.
4. **Microsoft Entra ID** – Manages users, identities, authentication, and access to cloud resources.

## Three Advantages

1. **Microsoft Integration** – Azure works well with Microsoft products such as Windows Server, Microsoft 365, and Microsoft Entra ID.
2. **Hybrid Cloud Support** – Azure can connect cloud services with existing company servers and systems.
3. **Enterprise Features** – Azure provides security, identity, management, and other services useful for large organizations.

## Typical Enterprise Use Cases

Azure can be used for Windows Server applications, company websites, databases, virtual machines, Microsoft 365 environments, hybrid cloud systems, virtual desktops, and business applications. It is also useful for organizations that already use Microsoft technologies.
